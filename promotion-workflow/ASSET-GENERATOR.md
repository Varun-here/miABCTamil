# miABCTamil asset generator

Start this section by saying: **“Run the asset generator.”**

The workflow will ask what you want to make and collect the relevant materials at that point. Nothing needs uploading while you are setting up the workflow.

| Choose | Materials needed | Output |
|---|---|---|
| One-pager | Deck or approved product brief; market analysis for any market claims | Editable DOCX or a one-slide PPTX |
| Presentation | Deck, purpose, audience and current supporting analysis | Editable PPTX |
| Tamil Sounds Module demo | Actual screen recording or working module access | MP4 when footage and rendering tools are available, with captions and script |
| Karunya testimonial | Authentic quote, confirmed attribution and permission for public use | Quote image, caption, document section or slide |

## During the run

1. Choose an asset, audience and purpose.
2. Provide the requested sources and any language or branding preferences.
3. The assistant checks the sources and creates the supported asset.
4. Review the actual preview and request changes.
5. Receive local files, source notes and an updated workflow record.

Example requests:

- “Turn this deck into a one-page DOCX for school leaders.”
- “Use this deck and market report to create a five-slide investor introduction.”
- “Turn this module recording into a 30-second captioned demo.”
- “Create a bilingual testimonial image from this approved quote.”

The generator instructions are configured. No deck-based document, module MP4 or authentic testimonial has been generated yet because those source materials have not been supplied. A script or storyboard is identified as such and is not presented as a finished video. AI generation uses the connected assistant session; the resulting files can be used offline.
