# Your miABCTamil promotion workflow

Give Codex a short brief and it will create your campaign files, outreach drafts, requested documents and tracker updates. These files can be read and edited offline. New AI generation in Codex requires an internet connection, but this chat workflow needs no separate API key.

## Start with one message

> Use the miABCTamil promotion workflow. Create next week's campaign for Tamil diaspora parents and adult beginners: three bilingual posts, one parent explainer, one 30-second video script, and cold and warm school outreach drafts. Use the materials I supply. Save the files and update my tracker.

You can also ask:

- “Draft a school introduction from this recipient list.”
- “Turn this deck into a DOCX one-pager and a five-slide PPTX.”
- “Make a demo storyboard from this screen recording.”
- “I sent O001 today. Record it in the tracker.”
- “Review this week's replies and suggest the next campaign.”

## Your working files

- `BRAND-BRIEF.md`: known facts and details to add once.
- `INPUT-BRIEF.md`: optional short form for any request.
- `ASSET-GENERATOR.md`: start an asset run for one-pagers, slides, actual module demos or approved testimonials.
- `sources/`: save real product materials, deck, market analysis, screenshots and approved quotes here.
- `miABCTamil-Tracker.xlsx`: Outreach and Calendar tabs with filters, dropdowns and calculated outreach totals.
- `TRACKING.md`: how to record sends, replies and conversions through chat or Excel, and review results.
- `FIRST-CAMPAIGN.md`: existing sample drafts, still awaiting review.
- `SESSION-STATE.md`: handoff for your next session.
- `miabctamil-promotion/SKILL.md`: portable assistant instructions.

If the skill is installed, say `$miabctamil-promotion` plus your request. Otherwise ask Codex to read `miabctamil-promotion/SKILL.md` in this folder. In a new workspace, provide this folder or its location and the latest workbook.

## What you provide

Start with the audience and what you want to make. Add the official app link and approved product information when available. Source-dependent work needs the actual materials: pilot findings for outcomes, a deck for investor messaging, recordings for a real demo, and approved quotes for testimonials.

This is an on-request workflow. It creates drafts and local files. Weekly means you ask for the next week; no background schedule has been created. Email sending and social publishing are not connected. Videos begin as scripts/storyboards unless footage and a rendering tool are available.

## Tracker conventions

One Outreach row represents one recipient in one campaign. Keep follow-ups on that row. Fill First sent only after sending. Enter Yes/No only after checking an outcome, and record Checked date. Leave unknown outcomes blank. Define a conversion, such as a booked demo, before reporting it.

Summary counts cover entered rows across all campaigns. Rates use only sent records with measured Yes/No outcomes; measured coverage is shown beside them. Zero logged sends does not assert that you have never sent outreach elsewhere. The workbook has 200 prepared rows per tab. Ask Codex to extend it when needed.

Keep local backups before substantial manual edits. Nothing in this folder contains an API key.
